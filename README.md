# Mai Footwear — Wholesale Catalogue

Responsive static catalogue built from the nine uploaded PDF catalogues and the uploaded JPG shoe photos. Product images are included in `assets/products/`. Search and category filtering are included.

**Review before publishing:** some PDF pages use temporary labels like `PDF01-01` where a style code was not verified. Please check these labels and any sizes/pack quantities against the original catalogue.

## Set contact details
Open `products.js` and set `whatsappNumber` to your WhatsApp number in international digits only (South African example: `27...`).

## Publish with GitHub Pages
1. Create a repository such as `mai-footwear-catalogue`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. GitHub will show the website URL after deployment.
